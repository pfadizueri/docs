# Kursordner freigeben

Grundsätzlich werden die Dateien der Kurse der Kantonsebene im SharePoint der Kantonsebene abgelegt. Dort gehören sie in den Ordner «20 Ausbildung» und in den entsprechenden Unterordner gemäss A-Team.

Kursordner können für Kursteammitglieder ausserhalb der Kantonsebene freigegeben werden. Nachfolgend dazu eine Schritt-für-Schritt-Anleitung:

## 1. Ordner teilen
Klicke auf das «Teilen»-Icon neben dem betreffenden Ordnernamen.

_Foto folgt_

## 2. Linkeinstellungen öffnen
Klicke im Freigeben-Dialog auf das Zahnrad-Icon, um die Bedingungen für den Link zu verändern.

_Foto folgt_

## 3. Link konfigurieren
Im Popup müssen die Punkte wie folgt konfiguriert werden:
- **Link teilen mit:** Jeder (für jeden freigeben, keine Anmeldung erforderlich)
- **Berechtigung:** Kann anzeigen
- Optional kannst du ein Ablaufdatum setzen
- Ganz unten kann ein Kennwort für das Teilen festgelegt werden

Speichere die Einstellungen anschliessend mit «Übernehmen».

_Foto folgt_

## 4. Link kopieren
Der Link zum Teilen kann über den Knopf «Link kopieren» kopiert und z.B. per E-Mail an die Kursteammitglieder verschickt werden.

_Foto folgt_
